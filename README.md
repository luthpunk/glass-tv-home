## ✨ Fitur Utama

### 1. Desain Apple tvOS Frosted Glass & Tampilan Bersih
- **Dock Kaca Buram (*Frosted Glass*) di Baris Pertama**: Baris utama aplikasi dibungkus *tray* kaca buram yang mem-blur wallpaper di belakangnya secara *real-time*, sedangkan baris di bawahnya tampil melayang bersih agar tidak menutupi keindahan wallpaper.
- **Sorotan Mengalir (*Gliding Focus*), Kerangka *Gradient Glass Rim* & *Ambient Glow***: Sorotan kaca berpindah mulus antar-aplikasi dilengkapi bingkai gradasi diagonal (`1.5dp`) yang kontras baik di banner gelap maupun putih, serta pencahayaan latar (*ambient glow*) yang otomatis menyesuaikan warna *banner* aplikasi.
- **Peredupan Wallpaper Otomatis (*Dark Dimming*)**: Setiap wallpaper otomatis diberi *tint* gelap (`#6E6E6E`) agar jam, teks lokasi, dan ikon aplikasi selalu kontras dan nyaman di mata.
- **Antarmuka 100% Bahasa Indonesia & Bebas Menu Azan/Doa**: Seluruh menu, pengaturan, dan status cuaca telah diterjemahkan ke Bahasa Indonesia serta dibersihkan dari fitur/menu jadwal salat, azan, dan doa.

### 2. App Drawer 6x6 Bertema Frosted Glass
- **Kartu "Aplikasi" Berikon Kotak 3x3 Glass**: Menggantikan aplikasi *App Drawer* bawaan STB (`com.arvanasoft.aplikasi`) dengan kartu khusus bergambar **9 kotak (3x3) Frosted Glass** di tengahnya. Kartu ini juga bebas dipindahkan posisinya (*Move*) seperti aplikasi lainnya.
- **Panel Semua Aplikasi (Grid 6x6)**: Membuka jendela *Frosted Glass* berisi seluruh aplikasi yang terinstal dalam tata letak **6 kolom (6x6)**.
- **Dukungan Penuh *TV Banner* `16:9` & Aplikasi *Sideload***: Menampilkan *banner* persegi panjang khas Android TV secara utuh, dan otomatis menampilkan ikon kotak asli di tengah kartu kaca untuk aplikasi non-TV hasil *sideload* (seperti **Magisk**).
- **Aksi Cepat**: Tekan **OK** untuk membuka aplikasi, atau **Tahan OK** untuk membuka pengaturan **Info Aplikasi / Paksa Berhenti / Uninstall**.

## 🚀 Cara Instalasi via ADB (Wi-Fi)

1. Aktifkan **Opsi Pengembang (Developer Options)** dan **USB / Wireless Debugging** di Android TV / STB Anda.
2. Hubungkan lewat ADB dan pasang APK:
   ```bash
   adb connect <IP_TV_ANDA>:5555
   adb install -r release/glass-tv-home.apk
   ```
3. Jadikan **Glass TV Home** sebagai launcher utama (opsional jika menonaktifkan launcher bawaan):
   ```bash
   adb shell cmd package set-home-activity com.gathin.tvhome/.MainActivity
   ```
